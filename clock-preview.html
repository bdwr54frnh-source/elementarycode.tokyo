Elementary Code

Elementary Code is a new authentication code generated within the dedicated application.

The code is embedded in a transmission icon. By checking the icon with a compatible application and device, the connection with the other party can be authenticated.

One of its key features is that communication can be initiated through a dedicated transmission icon without directly sharing a conventional telephone number.

How it works

  1. Generate a transmission icon within the dedicated application.
  2. The Elementary Code is embedded in the icon.
  3. The recipient checks and authenticates the code using the compatible application.
  4. Once authentication is completed, communication can begin.

Elementary Code is not simply a displayed number or character string. It is designed to authenticate the relationship between the transmission icon and the other party by combining the dedicated application with a compatible device.

Authentication is designed to be completed in a short period of time.

For security and technical reasons, the specific generation, verification algorithms, and internal technical specifications are not publicly disclosed.

エレメンタリーコード

エレメンタリーコードは、専用アプリの中で生成される、新しい認証コードです。

発信アイコンに組み込まれたエレメンタリーコードを、対応するアプリと端末で確認することで、相手とのつながりを認証します。

通常の電話番号を直接伝えることなく、専用の発信アイコンを通してコミュニケーションを始められることが大きな特徴です。

かんたんな仕組み

  1. 専用アプリで発信アイコンを生成します。
  2. アイコンにエレメンタリーコードが組み込まれます。
  3. 相手側の対応アプリでコードを確認・認証します。
  4. 認証が完了すると、コミュニケーションを開始できます。

エレメンタリーコードは、単なる数字や文字列を表示するためのものではありません。専用アプリと対応する端末を組み合わせて確認することで、発信アイコンと相手との関係を認証するための仕組みです。

認証は短時間で行える設計になっています。

安全性と技術上の理由から、エレメンタリーコードを生成・検証する具体的なアルゴリズムや内部仕様の詳細は公開していません。

エレメンタリーコード｜次世代の認証を目指して

Elementary Code（エレメンタリーコード）は、電話番号やパスワードの入力に頼らず、対応するアプリと端末で接続直前にコードを確認する認証の仕組みとして開発を進めています。目指すのは、利用者の手間を減らし、相手との接続を素早く確認できる技術です。

サッカー選手の写真と、本物の相手を確認する方法

たとえば有名なサッカー選手の顔写真が付いたアイコンを受け取ったとしても、写真だけでは、その選手本人から届いたものかどうかは分かりません。写真が本物であることと、送信者が本人であることは別の問題です。

エレメンタリーコードが目指すのは、写真の見た目を鑑定することではありません。受け取ったアイコンに紐付く正規の接続先を、対応アプリによる呼び出しと接続前のコード照合で確認できる仕組みです。本人確認済みのアカウントと紐付いている場合に限り、その接続結果を本人確認の手掛かりにできます。

※単につながるだけではサッカー選手本人だと証明できません。最初の登録時に本人確認が行われ、アイコンと本人の接続先が正しく紐付いていることが前提です。これは開発中の仕組みの説明であり、現在提供中の機能を示すものではありません。
