# ホームページ作成・修正時の必須テンプレート

**ホームページの新規作成・修正時は、必ずこのテンプレートを確認してから作業すること。**

## 必須ルール
1. PCとスマートフォンの両方に対応するテンプレートを使用する。見出し・本文サイズの勝手な自動縮小は禁止。
2. 既存の漫画画像は構図・文字・絵・トリミングを無断変更しない。画像差し替えは依頼者が承認した正しい原本を使う。
3. 漫画第2コマの時計は指定の位置に表示し、LIVE化は別途実機検査する。静止表示とLIVE動作を混同しない。
4. ELEMENTARY CODEは個人の身元確認ではなく、デバイスとAI CODEの紐付け・認証を説明する。氏名・住所・免許証の提出を前提にしない。
5. 『個人の身元と結びつけるためのコードではありません』を基本説明に使用する。絶対的匿名性を断定しない。
6. 双子コード・内部認証ロジック・秘密情報を公開しない。持ち主への表示は8桁シリアル番号と個別URLを基本とする。
7. 未実装の機能を実装済みと表示しない。
8. 本番公開前にPCとiPhoneで確認する。公開指示の範囲を超える変更をしない。
9. WordPressおよびLolipopは使用しない。
