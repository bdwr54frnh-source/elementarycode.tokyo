# ELEMENTARY CODE — 管理カード設計 v1

作成日: 2026-10-14

## 登録カード項目
- 登録日時: UTC ISO 8601、登録地の現地日時とUTCオフセット（±HH:MM）
- タイムゾーン: IANA TZID（例: Asia/Tokyo）。表示時の時差は当該日時に対して計算し、夏時間に対応
- 登録時座標由来の下4桁: **管理カード用の管理番号**として扱い、ELEMENTARY CODE本体には組み込まない。抽出規則・重複時の識別方法は実装前に確定する
- 親コード・双子コード: カードには鍵そのものを保存せず、非機密な識別子・状態・有効期限のみ表示
- 更新周期: 利用者が選択・変更可能
- 鍵の失効: 利用者がいつでも実行可能
- 対象端末・相手の限定: 利用者が選択可能

## プライバシー・セキュリティ
- 位置情報は明示的な許可を得た初回登録時にのみ取得。常時追跡・移動履歴収集を行わない
- 位置情報の末尾桁や時差は秘密情報ではない。認証の根拠に単独利用しない
- 座標の末尾桁も位置情報に由来するため、保存・同期は明示同意と削除手段を備える
- 公開GitHub Pagesには個人別管理カード・認証秘密情報を配置しない
- 認証鍵は暗号学的乱数から生成し、検証・失効は保護された認証基盤で実施する
