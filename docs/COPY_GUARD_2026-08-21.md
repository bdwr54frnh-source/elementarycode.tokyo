# Elementary Code 公開ページ・コピー対策（社長 2026-08-21）

こーちゃん担当。完全コピー防止ではない。

## 正

**簡易コピーガード ＋ 本物認証を優先。**

## 頼む内容（これだけ）

1. 右クリック禁止
2. 文字選択・コピー禁止（入力欄は除く）
3. 画像ドラッグ保存をしにくくする
4. ページ内の重要画像に透かし
5. ソースに重要ロジックや秘密情報を置かない
6. コピーされても本物として使えないよう、認証はアプリ側で判定

## いちばん大事（6）

ページの見た目をコピーされても、次はコピーできない構造にする。

- AIR の毎回認証
- 最新認証日時
- 履歴発信

VERIFIED／真正性は Air Face アプリ側の認証結果だけ。画像や HTML の見た目コピーでは付けない。

## やらないこと

- DRM 級の完全コピー防止を約束すること
- HTML/JS に秘密・内部ロジックを入れること
- 公開プロフィール項目をこの作業で消すこと
- Apple / Google 提出ビルドと混ぜること
